hexo+github创建第一个永久免费博客

第一部分，把博客搭建在我的电脑，单机 。（本地部署）
1. 下载安装环境node.js（下载后一键安装就不管了）
https://nodejs.org/en/

  1. 安装git bash（这个是部署hexo博客的软件）
    https://git-scm.com/download/win

  1. 新建一个文件夹，打开，在空白处右键打开git bash。输入第一条命令启用 Hexo镜像
    npm config set registry https://registry.npm.taobao.org

  2. 在 git bash 中输入第二条命令开始全局安装 Hexo
    npm install -g hexo-cli

  3. 在 git bash 中输入第三条：
    hexo init 自定义博客名。我的博客名是jinwandalaohu。所以输入hexo init jinwandalaohu
    这时会在文件夹下新建一个以博客名jinwandalaohu命名的文件夹，博客的本地部署都在这里面。重装系统要把这个文件夹内全部复制备份。

  4. 注意以上这些是打开新建文件夹，再右键打开git bash
    以下要关闭git bash打开新建的jinwandalaohu文件夹。右键打开git bash

  5. 输入：
    hexo g
    编译静态文件到public文件夹，这是根目录，会自动生成public文件夹

  6. 在 git bash 中输入：
    hexo s
    启动本地预览，关闭gitbash后,就无法预览

  7. 输入 http://localhost:4000 ，能正常访问，则启动成功
    到这里 就是电脑上部署成功，但是单机，要联网还得下一步

第二部分：本地与服务器建立联系
1. 将hexo代码提交到github仓库
注册github.com账号，jinwandalaohu@gmail.com.新建一个github仓库，仓库名必须是你的GitHub用户名.github.io，比如jinwandalaohu.github.io 目的是为了搭载 GitHub Pages 服务

  1. 再到git bash上生成密匙
    输入命令：
    ssh-keygen -t rsa -C “你注册github的邮箱”
    在本地电脑 C:\Users\xxx中找到新生成的公匙文件id_rsa.pub，记事本格式打开。复制其中一串乱码（公钥）

  2. 到github网站，点右上角图像，右边找到设置，左边点击SSH and GPG keys。新建一个-New SSH Key。把刚才复制的乱码粘贴过来。这一步的作用是让电脑与服务器连接起来。要服务器给我信的电脑授权。在电脑上生成一个钥匙，把这个钥匙填到服务器，就建立信任。

  3. 验证是否成功
    git bash上输入命令：
    ssh -T git@github.com
    出现shell access就表示成功。
    第三部分，推送和写博客

  4. 根目录里打开 _config.yml文件，记事本格式打开。找到文件最后一行的 deploy替换以下代码：
    deploy:
    type: git
    repo: https://github.com/你的github用户名/你的github用户名.github.io.git,main

  5. git bash上安装推送命令：
    npm install hexo-deployer-git –save

  6. 清理缓存，重新生成静态文件，推送到github的命令（这条命令在每次本地修改后都要重新打开git bash推送一遍才算完成一次博客更新）
    hexo clean && hexo g && hexo de
    这里要连接到github会有个弹窗验证，点开确认才能推送成功。

  7. 推送成功后，你的博客网站就能联网更新了。进入网站：你的GitHub用户名.github.io。比如jinwandalaohu.github.io

  8. 创建新博客
    git bash上输入命令：
    hexo n 博客的名称。比如：hexo n 我和第一篇博客
    再到F:\blog\sexyshroud\source_posts里找到这篇博客的文件夹，用记事本打开，写博客。
    最后回到git bash输入命令：
    hexo clean && hexo g && hexo de推送。博客就联网更新了。有时更新会比较慢
    或者再输入这三条命令：
    hexo clean
    hexo g
    hexo d

  9. 删除博客
    post文件夹里删除对应的markdown文件的同时删除掉.deploy_git文件夹。再输入推送命令。

  10. 其他命令
    版本号hexo -v

  11. 编辑技巧：
    显示文章摘要<!—more –>
    修改文章封面搜索根目录banner.jpg位置并替换。
